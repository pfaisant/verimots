Feuille de route

Dernière mise à jour : 26 août 2026.

Verimots est un projet indépendant, gratuit, sans publicité et sans budget. La ligne est simple : d’abord tout ce qui est libre et gratuit ; ensuite, quand le projet aura une audience et une méthode solides, explorer des licences officielles (ODS, CSW, NWL, Lexicón) — mais pas maintenant.

Où en est-on

  • Listes de mots communautaires, une par langue (FR, EN ×2, ES), sans copie d’ouvrage officiel.
  • Définitions tirées du Wiktionnaire (CC BY-SA 4.0), avec attribution dans l’app.
  • Modes de jeu : Bingo (classement hebdomadaire et général), Trouver un mot, Combinaisons, Petits Mots.
  • Web (s.pfa87.cc) et application Android native, même code de règles.

Phase 1 — Budget zéro : consolider avec des sources libres maintenant → fin 2026

  1. Dire clairement ce que Verimots est et n’est pas. Avertissements précis (page Infos, page Dictionnaires, fiches store) : listes communautaires, pas d’ODS/CSW/NWL/Lexicón, pas de conformité officielle, pas d’arbitrage de tournoi, marques SCRABBLE citées avec leurs titulaires.
  2. Documenter la provenance de chaque liste : source, licence, date d’import, méthode de construction et de nettoyage, choix d’inclusion/exclusion. Cette traçabilité est la meilleure protection contre le reproche d’« extraction » d’un ouvrage protégé.
  3. Définitions FR hors-ligne : extraire le Wiktionnaire FR (dumps + Wiktextract/Kaikki), le mapper sur la liste, embarquer un sous-ensemble compact dans l’app. Attribution CC BY-SA visible.
  4. Définitions EN : ajouter WordNet 3.0 (licence permissive, sans share-alike) pour les sens courants ; compléter par le Wiktionnaire EN pour les formes fléchies. Notice WordNet dans les crédits, sans usage du nom « Princeton » en promotion.
  5. Définitions ES : Wiktionnaire ES uniquement ; pas d’extraction du DLE (contenu RAE) ni d’usage du Lexicón FILE.
  6. Définitions communautaires pour les trous (mots de tournoi absents du Wiktionnaire) : courtes, rédigées par les joueurs, publiées sous CC BY-SA pour rester compatibles.
  7. Listes EN et ES indépendantes : consolider à partir de sources ouvertes (YAWL, SCOWL, listes CC0, RLA-ES MPL, fichiers publiés par la WGPO) et assumer l’écart avec CSW/NWL/FILE (« mode approximatif » signalé aux joueurs de tournoi).
  8. Hygiène : ne plus nommer ODS9 / CSW24 / NWL2023 dans le code et les données ; garder les noms de listes comme repères pour les joueurs, jamais comme revendication de conformité.

Phase 2 — Mesurer, puis frapper aux portes 2027, si l’audience le justifie

  1. Suivre l’usage (joueurs actifs, parties, langues) pour pouvoir décrire honnêtement le projet.
  2. Écrire pour clarifier, pas pour acheter : Larousse (licences numériques ODS) et FISF d’abord, puis HarperCollins (Collins API / CSW), NASPA (NWL), FILE (Lexicón). Question posée : existe-t-il un cadre pour une app gratuite, hors-ligne, sans publicité ? À défaut, confirmer que l’intégration est exclue — et rester sur le libre.
  3. Options « légères » à privilégier si une porte s’ouvre : lien vers l’outil officiel, API en ligne limitée, module co-brandé.

Phase 3 — Licences, seulement si accessibles non planifié

  • Aucun tarif public n’existe pour ODS, CSW, NWL ou Lexicón ; les accords se font au cas par cas.
  • Seule grille connue : Collins API (dictionnaire général, EN) — gratuit jusqu’à 5 000 appels/mois, puis 50 £, 170 £, 375 £ par mois selon le volume. Non compatible avec un budget zéro au-delà du palier gratuit.
  • Décision : pas de licence tant que le projet n’a ni budget ni besoin avéré. Le libre suffit pour apprendre et s’entraîner.

Ce que Verimots ne fera pas

  • Reproduire ou redistribuer l’ODS, le CSW, le NWL, le Lexicón FILE ou le DLE, même partiellement.
  • Se présenter comme « conforme » à un lexique officiel ou comme arbitre.
  • Ajouter de la publicité ou un paiement pour financer une licence.

Crédits et licences

  • Wiktionnaire / Wiktionary / Wikcionario — CC BY-SA 4.0 (définitions).
  • YAWL — domaine public (liste EN « CSW · YAWL »).
  • WGPO Official Words 2024 — fichier publié par la WGPO (liste EN).
  • RLA-ES 2.9 — Mozilla Public License 1.1 (liste ES).
  • À venir : WordNet 3.0 (Princeton University) pour les définitions EN.

In English — the short version

Verimots is free, ad-free and has no budget. Phase 1 (now): rely only on free sources — community word lists, Wiktionary (CC BY-SA), WordNet for English — with clear disclaimers and documented provenance. Phase 2 (2027, if usage justifies it): write to Larousse/FISF, HarperCollins, NASPA and FILE to clarify whether any framework exists for a free offline app. Phase 3 (unplanned): licences only if they turn out to be accessible. No official list is reproduced, and none will be without an agreement.
